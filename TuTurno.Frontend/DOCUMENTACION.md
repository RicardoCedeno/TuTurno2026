# Proyecto TuTurno 🏥

TuTurno es una plataforma integral de gestión para consultorios médicos, diseñada para optimizar la administración de citas, personal médico y registros de pacientes. El sistema se enfoca en ofrecer una experiencia fluida y profesional para el personal administrativo.

## 🎯 Público Objetivo

El software está diseñado exclusivamente para **Recepcionistas y Personal Administrativo** de consultorios y centros médicos.

*   **No es para médicos:** La interfaz está optimizada para la gestión rápida de agendas, no para historias clínicas complejas o diagnósticos.
*   **Enfoque:** Facilitar la atención al paciente desde su llegada, la asignación de turnos y la gestión de la disponibilidad de los doctores de manera eficiente.

## 🚀 Funcionalidades Principales

El sistema está dividido en módulos clave para cubrir todas las necesidades operativas de un centro médico:

1.  **Gestión de Citas (Appointments):** Creación, edición y seguimiento de turnos médicos en tiempo real.
2.  **Panel de Doctores:** Administración del personal médico, sus especialidades y datos de contacto.
3.  **Disponibilidad Médica:** Configuración flexible de horarios, días de atención y bloqueos de agenda para cada doctor.
4.  **Registro de Pacientes:** Base de datos centralizada con información de contacto y antecedentes básicos de los pacientes.
5.  **Especialidades:** Catálogo de servicios médicos ofrecidos por el centro.
6.  **Consultorios y Ubicaciones:** Gestión física de los espacios de trabajo y diferentes sucursales del centro médico.
7.  **Sistema de Cancelaciones:** Gestión eficiente de turnos cancelados para liberar espacios en la agenda automáticamente.
8.  **Dashboard de Inicio:** Resumen visual de las citas del día, estadísticas rápidas y acceso directo a las acciones más comunes.

## ✨ Características Técnicas de la UI
*   **Responsive Design:** Adaptable a tablets y computadoras de escritorio.
*   **Micro-animaciones:** Transiciones suaves que mejoran la experiencia de usuario.
*   **Glassmorphism:** Uso de efectos de desenfoque y transparencia para una estética premium.
*   **Dark/Light Mode:** Soporte nativo para cambio de tema según la preferencia del usuario.
