# TuTurno Social Ad Spec

## Objective

Create an aesthetic, premium social ad for `TuTurno` aimed at clinics, doctors, and healthcare businesses that could buy the software.

The creative should feel:

- modern
- trustworthy
- elegant
- conversion-focused

Avoid a generic corporate healthcare look. This should feel like a polished SaaS campaign.

## Primary Piece

Use this as the main Figma frame:

- Frame name: `TuTurno - Instagram Feed 01`
- Size: `1080 x 1350`
- Layout grid: `12 columns`
- Margin: `72 px`
- Gutter: `24 px`
- Safe zone for text/CTA: keep the main copy within the central `936 px` width

## Visual Direction

- Background: warm ivory with subtle soft gradient
- Accent color: premium teal
- Secondary color: deep green
- Support accent: muted coral/salmon
- Style: editorial SaaS, clean whitespace, soft shadows, crisp UI mockup
- Imagery: elegant doctor/patient lifestyle photo or a refined healthcare environment
- Product signal: iPhone-style app mockup showing appointments/calendar

## Color Palette

- Ivory: `#F6F1EA`
- Soft Sand: `#E8DED2`
- Premium Teal: `#1E8C89`
- Deep Green: `#113B36`
- Muted Coral: `#D98972`
- Charcoal Text: `#1C2423`
- White: `#FFFFFF`

## Typography

If available in Figma, use:

- Headline: `Cormorant Garamond Semibold` or `DM Serif Display`
- Body/UI: `Manrope` or `Plus Jakarta Sans`

Suggested sizing:

- Eyebrow: `22 px`, medium, uppercase with letter spacing `4%`
- Headline: `78 px`, semibold, line height `90%`
- Supporting copy: `28 px`, medium, line height `130%`
- Feature bullets: `24 px`, medium
- CTA button: `24 px`, semibold
- Micro label inside mockup callouts: `18 px`, medium

## Composition

Build the layout in 3 visual zones:

1. Top editorial copy block
2. Center-right product mockup
3. Bottom-left value points + CTA

Suggested structure:

- Top left: small eyebrow text
- Below it: strong headline in 3-4 lines
- Mid left: short support paragraph
- Right side: phone mockup tilted slightly or perfectly vertical
- Behind mockup: soft shape or gradient panel
- Bottom left: three business benefits
- Bottom right or bottom center: CTA button + website/demo line

## Figma Build Notes

### Background

- Use ivory as the base
- Add a subtle radial gradient from top right using soft sand to transparent
- Add one large blurred organic shape behind the phone in soft teal at `10-14%` opacity

### Product Mockup

The screen should suggest:

- doctor calendar
- appointment list
- specialty tag
- confirmation/reminder state

Suggested screen labels:

- `Citas de hoy`
- `Cardiologia`
- `Paciente confirmado`
- `Recordatorio enviado`

Keep the UI minimal and clean, not too detailed.

### CTA Button

- Fill: premium teal
- Radius: `18 px`
- Padding: `18 px` vertical, `28 px` horizontal
- Text color: white
- Add a subtle shadow

### Benefit List

Use three short lines with either:

- small teal dots
- minimalist check icons

Keep spacing airy.

## Export Variants

After the main frame, duplicate and adapt to:

- `1080 x 1080` for Instagram/Facebook square
- `1200 x 1500` for Facebook feed
- `1080 x 1920` for story/reel cover

## Quick Adaptation Rules

For square format:

- reduce headline to 3 lines maximum
- move phone mockup slightly lower
- keep CTA visible above the fold

For story format:

- enlarge the phone
- shorten headline
- keep benefits to only 2 lines
- place CTA near the lower third

## Suggested Image Prompt

Use this if you want to generate the hero visual separately:

`Elegant premium healthcare SaaS campaign image, modern clinic atmosphere, refined medical professional, soft natural lighting, editorial composition, clean luxury aesthetic, teal and ivory palette, trustworthy and aspirational, suitable for a high-end appointment booking software ad`

## Best Use

This concept works best when the ad is selling:

- digital transformation for clinics
- better appointment management
- a more premium patient experience
- fewer missed appointments

It is stronger for B2B sales than for end patients.
